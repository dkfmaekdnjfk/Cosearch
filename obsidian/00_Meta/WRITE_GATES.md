# WRITE_GATES

[[ANSWER_GATES]]를 적용한 뒤 문서를 작성하기 직전에 확인한다.

## 게이트

**G1. 출처를 찾을 수 있는가?** 파일·줄 또는 논문 표·행·열을 남긴다.
확인하지 못한 내용은 추정·미확인으로 표시하고 정량 근거로 사용하지 않는다.

**G2. 기존 기록과 새 제안을 구분했는가?** 새 용어·구분·해석은 제안임을 밝힌다.
검정이 어렵다는 이유로 측정이나 실험 설계의 축을 임의로 바꾸지 않는다.

**G3. 최신 파일과 관련 정의를 읽었는가?** 기존 기능·참조를 확인하고 필요한 부분만 수정한다.
검증된 분석 구조와 스타일을 바꾸려면 이유와 영향을 기록한다.

**G4. 결론 변경이 관련 문서에도 반영되는가?** 본문뿐 아니라 태그·상태·별칭·순위와
같은 전제에 의존하는 문서를 검색한다. 같은 오류가 반복되면 패턴으로 전체 볼트를 확인한다.

**G5. 분석과 그림이 같은 방법을 설명하는가?** 분석이 바뀌면 기존 그림의 유효성도 검토한다.
그림 또는 연결된 설명에 대상·독립 표본 수·전처리·분석 파라미터·코드·실행 조건을 기록한다.

**G6. 검증 상태가 정확한가?** 원문 확보와 실제 대조는 다르다.
검증 범위와 남은 항목을 표시하며 미검증 자료를 검증된 근거로 인용하지 않는다.

**G7. 수정 후 다시 확인했는가?** 파일을 다시 읽고 diff를 확인한다.
의도한 변경과 누락·삭제 여부를 확인하며 사용자가 정한 사항을 임의로 뒤집지 않는다.

## 유지 관리
