# 용어집

프로젝트의 용어 정의와 사용 규칙을 관리한다. 공통 템플릿에는 운영 규칙만 제공하며,
프로젝트별 용어·기호·금지어·감시어는 해당 프로젝트에서 확인한 근거로 등재한다.
관련 기록: [[HUMAN_CORRECTIONS]]. 한국어 문체는 `korean-copy` 스킬을 적용한다.

## 1. 기본 원칙

- 표준 용어가 아닌 명칭은 사용 전에 정의를 등재한다. 등재할 수 없으면 사용하지 않는다.
  신조어는 기본적으로 금지하며, 등재는 정의와 필요성이 확인된 경우의 예외다.
- 전문 용어는 영문 원문에 명칭이 있으면 해당 명칭을 우선한다. 영문 명칭을 추정하거나
  임의 번역어·약어를 생성하지 않는다. 영문 명칭이 없으면 한자어 전문용어를 사용한다.
- 표준 용어도 원문과 정의를 확인한다. 익숙한 표현이라는 이유로 다른 개념에 사용하지 않는다.
- 프로젝트에서 처음 사용하는 전문 용어는 최초 사용 위치에 정의를 병기한다.
- 정의는 예시의 나열이 아니라 개념의 판별 기준으로 작성한다. 적용 조건과 범위를 명시한다.
- 대립하는 분류 명칭은 같은 기준에서 구분한다. 상위 개념과 하위 기전을 대립쌍으로 제시하지 않는다.
- 용어집은 정의의 위치를 연결한다. 정의·유도·근거의 정본 문서 하나를 지정하고,
  다른 문서는 정본으로 연결한다.

## 2. 등재 절차

1. 원논문·공식 문서·프로젝트의 기존 정의를 직접 확인한다. 영문 표기와 출처를 기록한다.
2. 용어·영문 표기·약어를 프로젝트 문서와 관련 코드에서 검색한다. 기존 의미와 충돌하는지
   확인하고 검색 범위·기존 용법·점검 결과를 기록한다. 새 기호도 기존 사용을 확인한다.
3. 정의, 구분 기준, 적용 조건, 정본 위치를 작성한다. 새 명칭이 기존 명칭과 다른 이유를 기록한다.
4. 아래 용어표에 등재한 후 문서에 사용한다. 같은 개념에 여러 명칭을 임의로 사용하지 않는다.
5. 사용 문서를 다시 확인한다. 영문 표기·정의·분류 기준이 용어집과 일치하는지 대조한다.

검색은 프로젝트가 지정한 실제 문서·코드 경로를 사용한다. 다음은 기본 vault 검색 예시다.

```bash
rg -n -F -- '확인할 용어' obsidian/
```

### 용어표

| 용어·영문 원문 | 정의·판별 기준 | 구분 기준·적용 조건 | 충돌 점검 결과 | 정본 위치·원문 근거 |
|---|---|---|---|---|

표가 비어 있는 상태는 프로젝트 용어가 아직 등재되지 않은 상태다.

## 3. 금지어와 감시어

### 금지어

금지어는 사용을 중단하고 등재된 대체 표현을 사용한다. 금지 여부를 매번 되묻거나
감시어로 취급하지 않는다. 금지 사유·적용 범위·근거를 함께 기록한다.
문맥에 따라 정상적인 의미가 있는 낱말은 낱말 전체를 금지하기 전에 적용 범위를 구분한다.

<!-- BANNED:START -->

| 금지어 | 대체 표현 | 금지 사유·적용 범위 | 근거 |
|---|---|---|---|

<!-- BANNED:END -->

### 감시어

감시어는 금지어가 아니다. 과거에 오용한 표준 용어를 등록하고, 사용 대상이 실제 정의를
충족하는지 확인한다. 정의에 맞으면 유지하고, 맞지 않으면 올바른 명칭으로 수정한다.
오용 사례와 확인해야 할 판별 기준을 기록한다.

<!-- WATCHLIST:START -->

| 감시어·영문 원문 | 실제 정의·판별 기준 | 오용한 의미·수정 표현 | 교정 기록·근거 |
|---|---|---|---|

<!-- WATCHLIST:END -->

금지·감시 어휘는 프로젝트별 근거에 따라 추가한다. 다른 프로젝트의 목록을 그대로 복사하지 않는다.
표식은 목록 구간을 구분하며, 표식 자체가 자동 검사를 실행하지는 않는다.

## 4. 수정·폐기 절차

1. 변경할 정의의 정본과 원문 근거를 확인한다. 용어집만 읽고 정의를 변경하지 않는다.
2. 기존 용어·약어·기호를 검색하여 사용 문서와 관련 코드를 확인한다.
3. 새 정의나 명칭을 등재하고 변경 이유·근거·영향 범위를 기록한다.
4. 현재 작성·관리하는 문서의 명칭과 링크를 수정한다. 단어만 일괄 치환하지 않고
   문장의 개념과 조건을 확인한다.
5. 폐기 명칭과 대체 명칭의 대응을 아래 표에 기록한다. 사용자 교정은 [[HUMAN_CORRECTIONS]]에 연결한다.
6. 외부에서 수신한 원문, 직접 인용, 이미 전달한 문서 등 보존 대상은 임의 수정하지 않는다.
   교정 사항은 별도 기록으로 연결한다. 금지어 자체를 설명하는 언급과 개념 명칭으로 사용하는 경우도 구별한다.

| 이전 명칭 | 현재 명칭·처분 | 변경 이유 | 근거·교정 기록 |
|---|---|---|---|

## 5. 윤문 스킬과의 연계

- 윤문 전 관련 용어와 금지·감시 목록을 확인한다. 원문 근거가 필요한 용어는 정본 위치를 직접 연다.
- 영문 원어 우선 규칙과 용어집의 표기를 함께 적용한다.
- 윤문 중 새 명칭이 필요하면 먼저 2절의 등재 절차를 수행한다. 문장에 먼저 사용한 뒤 소급 등재하지 않는다.
- 금지어는 대체하고 감시어는 정의를 대조한다. 윤문을 이유로 정의나 분류 기준을 변경하지 않는다.
- 윤문 후 용어 표기와 정본 연결을 확인한다. 문서 첫머리의 용어표는 본 용어집의 정의를 참조하며
  별도 정의 정본으로 운영하지 않는다.
- 구어체·대명사·엠 대시·꺽쇠 금지는 윤문 스킬의 공통 규칙으로 유지한다.
