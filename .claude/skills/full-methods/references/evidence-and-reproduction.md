# 근거·재현 연결 기준

## 코드 대조와 추적

연구 설명과 실제 계산의 연결을 독자가 확인할 수 있도록 다음 정보를 제공한다.

| 항목 | 기재할 내용 |
|---|---|
| 코드 위치 | 프로젝트 기준 상대 경로, 실제 함수명, 검토한 버전의 시작·끝 행 번호, 소스 해시 또는 commit |
| 수행 연산 | 해당 함수가 수행하는 계산과 본문의 어느 절·수식·그림을 뒷받침하는지 |
| 입력 | 실제 경로·파일 형식·배열 이름·축·단위·관측 단위·자료의 생성 단계 |
| 산출물 | 실제 경로·행/배열의 구성·주요 열의 의미·조건을 대응하는 식별자 |
| 적용 설정 | 기본값과 호출 인자, 포함·제외 규칙, 정규화·평균·변환 순서 |
| 검증 | 읽고 대조한 코드 범위, 수치 대조 대상·허용오차·결과, 재실행 여부 |

- 원자료, 전처리된 입력, 통계량 캐시, 보고용 표, 화면용 데이터를 구분한다. ‘raw’라는 변수명만으로 원자료라고 서술하지 않는다.
- 초기 분석의 검정·보정과 후속 보고 기준이 다르면 각각의 생성 함수와 최종 적용 경로를 연결한다. 저장된 보정 열이 실제 그림에 사용되는지 확인한다.
- 코드의 행 번호는 검토한 소스 버전에 한정된다. 코드가 변경되면 소스 해시와 행 번호를 다시 확인한다. 과거 실행 해시와 현재 소스가 다르면 변경 여부와 저장 수치의 재현 여부를 구분한다.
- 실제 계산 함수의 위치를 제시한다. 결과를 HTML에 넣는 exporter, 그림 renderer 또는 README 경로만으로 계산 근거를 대신하지 않는다.
- 코드 대응표와 자료 대응표는 유용한 형식이다. 작은 분석에는 간결한 목록도 가능하다. 구현 전체를 본문에 붙이거나 개발용 변수 문서를 별도로 의무 생성하지 않는다.

## 재현 명령

- 프로젝트 기준 작업 폴더, 진입점·옵션·입력·출력, 필요한 실행 환경을 기재한다.
- 원 분석 생성, 저장 캐시에서 표 재생성, 보고 기준 적용, 그림 생성, HTML 생성과 검증 명령을 구분한다. 현재 개정본에 반영된 수동/후속 편집을 초기 exporter가 모두 재현한다고 서술하지 않는다.
- 보존된 출력이 있을 때 중단하는 조건, 경로를 지정하는 옵션과 실제 쓰기 대상을 확인한다. 재현을 위해 원 결과 삭제를 기본 절차로 제시하지 않는다.
- 기록에 있는 명령과 이번에 실제 실행한 명령을 구분한다. 실행하지 않은 생성 명령을 검증 완료로 보고하지 않는다.
- 가능하면 저장된 전체 입력·통계량을 읽는 별도의 검산으로 확인한다. 일부를 확인한 경우 확인한 조건·배정·수량을 명시하고 전체 검증으로 확대하지 않는다.
- 재생성 도구를 제공하면 원본 보존, 다른 편집본 덮어쓰기 방지와 결과 비교를 지원한다. 도구의 이름이나 내부 작업 이력을 연구 제목에 표시하지 않는다.

## 참고문헌과 원문

각 문헌에 서지 정보·DOI/공식 링크·보존 원문과 해당 원문의 **쪽·절·표·수식 위치**를 기재한다. PDF 쪽과 인쇄 쪽이 다르면 구분한다.

1. 인용하려는 정의·수식·가정을 실제 원문에서 확인한다. 검색 요약이나 다른 연구노트의 요약을 원문 대조로 보고하지 않는다.
2. 어떤 본문 절·수식·구현을 해당 문헌이 뒷받침하는지 연결한다. 일반적 수학 원리의 근거를 해당 분석의 자료·분석 범위·선정 규칙 전체의 검증으로 확대하지 않는다.
3. 연구책임자·공동연구자의 지침, 문헌의 방법과 프로젝트에서 추가한 설계를 구분한다. 전달된 지침은 실제 절을 연결하며 지침에 없는 내용을 귀속하지 않는다.
4. 공식 소프트웨어 문서는 함수·해당 설명 항목과 연결한다. 원리만 참고하고 직접 구현한 경우 실제 함수 호출을 했다고 쓰지 않는다.
5. 미확보·미검토 자료는 상태를 명시한다. 현재 결론의 근거로 사용할 수 없는 참고자료를 확정 결과와 섞지 않는다.

## ZIP 전달

사용자가 ZIP 생성을 요청한 경우에만 수행한다. 별도 공유·업로드·이메일 송신은 ZIP 생성 요청에 포함되지 않는다.

- 최신 보고서와 사용자가 보존한 원본을 구분하고, 압축을 푼 폴더에서 바로 열 수 있는 시작 파일을 제공한다.
- 보고서의 실제 상대 링크를 따라 필요한 보조 HTML·그림·수식 자원·저장 원문·코드·수치 자료를 수집한다. 재현 스크립트가 추가로 요구하는 입력·캐시·manifest도 포함한다.
- 연구 자료의 공유 범위는 사용자 요청을 따른다. 전체 원자료나 프로젝트 폴더를 무조건 묶지 않는다. 코드/전체 분석 재실행에 필요한 자료와 보고서 열람·저장 수치 검증에 포함한 자료의 범위를 명시한다.
- 원본은 변경하지 않고 배포 사본에서 상대 경로·파일명 대응을 처리한다. 별도 보조 파일의 복귀 경로와 PDF 원문 경로도 확인한다.
- 파일 목록·역할·원 경로·배포 경로·SHA-256과 재현 범위를 기록한다. 자료 링크·재현 명령에는 사용자별 절대 경로를 사용하지 않는다. 가상환경·임시 파일·무관한 백업은 포함하지 않는다.
- 실제 ZIP을 다시 풀어 누락 파일·상대 링크·해시를 검사한다. 포함한 검증·재현 도구가 있으면 추출 사본에서 명시한 범위로 실행한다. 과학적 수치나 검정·그림이 패키징 때문에 달라지지 않았는지 확인한다.
