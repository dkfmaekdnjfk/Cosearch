# HTML 보고서의 목차와 탐색

목차는 문서 첫머리의 링크 목록이 아니라, 읽는 도중 필요한 설명으로 이동하는 수단이다. 긴 보고서의 새 작성이나 목차·레이아웃 변경에 적용한다. 짧은 문서에 복잡한 탐색 장치를 강제하지 않는다.

## 내용의 위계

- Methods와 Results처럼 큰 묶음을 먼저 세우고, 관련 주제를 소절로 배치한다. 재현 자료·긴 수치표·참고문헌은 본문과 구분한다.
- 목차의 대절·소절은 실제 본문 제목의 순서·번호·위계와 대응시킨다. 가능하면 같은 정의에서 생성하여 목차와 본문을 따로 유지하지 않는다.
- 구조를 바꿀 때는 본문의 절 인용·표·그림·수식 링크도 함께 맞춘다. 기존 앵커는 가능한 한 유지하고, 다른 문서나 원논문의 절 번호는 구별한다.
- 구조 변경을 내용 축약이나 분석 변경으로 확대하지 않는다. 기존 본문·수치·표·그림은 사용자 요청 범위에서 유지한다.

## 읽는 동안의 탐색

- 넓은 화면에서는 참고 문서에 맞춰 왼쪽 고정 또는 sticky 목차를 제공한다. 대절과 소절을 들여쓰기·간격 등으로 구별하고, 필요한 소절로 직접 이동하게 한다.
- 목차가 화면보다 길면 목차 목록만 독립적으로 스크롤한다. 본문은 문서 스크롤을 유지하고, 목차·본문의 영역과 스크롤 막대가 겹치지 않도록 한다.
- 좁은 화면에서는 목차를 접어 펼칠 수 있게 하며 본문 너비를 확보한다. 버튼의 펼침 상태·키보드 접근·고정 요소에 제목이 가려지는 문제를 고려한다.
- 색이나 장식보다 읽기 폭·본문과 목차의 대비·클릭 가능한 항목의 구분을 우선한다. 참고 디자인의 연구 대상·제목·전용 경로는 복사하지 않는다.
- 링크 목적지가 접이식 부록 안에 있으면 부록을 열고 해당 위치로 이동한다. 인쇄에서는 탐색 UI를 숨기고 본문 폭을 복원하며, 필요한 부록의 출력 방식도 정한다.

## 변경 후 확인

- 앵커의 중복·누락, 목차와 실제 제목의 대응, 절 번호와 문서 간 참조를 확인한다.
- 레이아웃·탐색을 바꿨다면 가능한 범위에서 실제 화면의 중간 소절 이동, 목차와 본문의 스크롤, 좁은 화면의 펼침 동작을 확인한다. 파일 대조와 실제 화면 확인을 구별하여 수행한 범위만 보고한다.
- 문구 수정만으로 화면 검사를 자동 확대하거나 별도 검사 파일·새 분석을 만들지 않는다. 사용자 제약과 변경 위험에 맞춰 확인한다.
- 사용자가 직접 화면을 확인하겠다고 지정하면 브라우저·computer use 검토를 추가하지 않는다. 이미 수행한 확인과 사용자가 담당하는 확인 범위를 구별한다.
