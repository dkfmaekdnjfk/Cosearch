# 비교 목적에 따른 표현 선택

형식부터 지정하지 말고 독자가 구별해야 할 관계를 먼저 정한다. 아래 선택은 후보이며 데이터 밀도와 표본 구조에 따라 달라진다.

각 패널의 x축과 y축에 무엇을 놓는지, 변수의 단위·연속성·선택 이유를 설계 단계에서 확정한다. 연속적인 측정·계산값과 비교를 위해 조절한 용량·시간 등의 설정값을 구별하고, 설정값이 이산적으로 지정되었는지 연속 범위인지 확인한다. 다른 축 변수도 연구질문의 비교에 적합한지 검토한다.

| 질문 | 유용한 표현 | 판단할 특징과 보완할 정보 |
|---|---|---|
| 같은 대상이 얼마나 변했는가? | 대응점·연결선, 변화량 dot plot | 선의 방향·변화량의 0선 기준 위치. 대상이 많으면 선이 겹치므로 분포와 대응 산점도를 분담한다. |
| 집단 평균 변화와 개별 이질성이 일치하는가? | 독립 표본의 점과 요약, 별도의 개별 분포 | 평균의 이동과 개별 변화 방향을 함께 읽는다. 많은 하위 표본을 독립 표본 수처럼 표시하지 않는다. |
| 증가·감소의 비율과 크기는? | 변화량 histogram·ECDF, 대응 scatter | 0선 양쪽의 비율과 분포의 범위. 작은 이동·큰 예외를 구분하고 baseline 크기도 필요하면 보완한다. |
| 이산적인 횟수가 어떻게 전환되는가? | 빈도표·transition heatmap·count를 표현한 scatter | 실제 가능한 수준과 이동 방향. 평활화가 존재하지 않는 연속 정밀도를 암시하는지 확인한다. |
| 자극 반응이 언제 나타나는가? | 같은 시간축의 trace·raster·heatmap | onset·baseline·반응 구간과 시간 경과. 예시 trace와 전체 표본의 정량화를 연결한다. |
| 상태 분리와 시행 산포는 다른가? | 공통 좌표의 trajectory·점군과 정량 비교 | 중심 이동과 상태 내부 산포를 분리한다. 저차원 투영에서 보이는 각도를 고차원 검정 결과로 대신하지 않는다. |
| 여러 조건의 차이를 비교하는가? | 같은 배치의 small multiples, 필요한 요약 패널 | 행·열·순서·축 범위를 통일한다. 공통 축이 차이를 가리면 확대 패널과 전체 범위를 연결한다. |

## 보존해야 할 정보

- 동일한 대상의 대응 키를 사용한다. 서로 다른 집단의 점을 임의로 연결하지 않는다.
- Jitter가 필요하면 측정 의미가 없는 축에서 제한적으로 적용하고 seed·방법을 고정한다. 양축이 측정값인 scatter는 점의 크기·투명도·빈도 표시 등을 먼저 검토한다.
- 같은 값의 겹친 점은 빈도를 숨길 수 있다. 독립 표본 수가 작으면 각 점을 셀 수 있게 하고, 많으면 count·density와 표본 수를 함께 표시한다.
- Histogram은 bin 경계·단위·count 또는 비율을, ECDF는 누적비율의 분모를 정의한다. 조건마다 다른 bin으로 시각적 차이를 만들지 않는다.
- Heatmap의 정렬 기준을 기록한다. 조건별 독립 정렬로 세포의 재배열을 가리지 않는다. 대응 대상 비교에는 같은 순서를 유지하거나 정렬 목적을 명시한다.
- 평균·SD·SEM·CI·시행 산포·모형 불확실성은 서로 다르다. 타원이나 음영을 자동으로 CI라고 부르지 않는다.
- 축 일부를 숨긴 확대 그림에는 전체 범위 또는 제외된 범위와 관측치 수를 제공한다. 패널별 확대 축을 사용한 뒤 크기를 공통 축인 것처럼 비교하지 않는다.

## Figure 전체의 논리

각 패널이 질문 정의, 대표 예시, 직접 정량 근거, 대조 중 어떤 역할인지 정한다. 논문에 따라 순서는 달라진다. 모든 figure에 실험 모식도나 별도의 결론 박스를 강제하지 않는다.

계획에는 독자가 확인할 관계를 구체적으로 적는다. 예: “대응선이 대부분 같은 방향인지, 변화량 분포가 특정 소수 대상에 의존하는지 확인한다.” 결과를 확인하기 전에 방향을 결론으로 확정하지 않는다.

참고 사례는 같은 그래프 종류라는 이유보다 같은 비교 과제를 해결하는지로 고른다. 설계 기록에 참고할 시각적 장치와 적용하지 않을 차이를 각각 짧게 적고, 완성 후 원그림과 나란히 비교한다. 여러 조건을 유지해야 한다면 반복되는 패널 배치·공유 범례·공통 축으로 탐색 부담을 줄인다. 설명 블록을 늘리거나 조건·색을 줄이는 것을 기본 해결책으로 삼지 않는다.

논문 원그림의 배치·색·선은 관찰 사실이다. 그 선택의 목적은 저자가 설명하지 않았다면 추론이다.

## 참고 figure의 근거 정리

새 figure나 큰 구성 변경에는 제작 전에 아래를 수행한다.

- [ ] 표현하려는 내용과 독자가 판단할 관계를 패널별로 정리하고, 축·관측 단위·조건·패널 배치·불확실성·표기 방식 중 근거가 필요한 선택을 나열한다.
- [ ] 사용자나 프로젝트가 제공한 참고 보고서의 원그림을 먼저 확인하고, 각 비교 과제와 자료 구조가 비슷한 실제 논문 figure를 찾는다. 가능한 경우 영향력 지수(IF)가 높은 저널의 피인용 수가 높은 논문을 우선 후보로 살펴본다.
- [ ] 논문 제목·저자·연도·저널·DOI 또는 공식 링크·figure와 패널 번호를 남긴다. 확인 가능한 경우 IF와 피인용 수의 출처·기준 연도 또는 조회일을 기록한다.
- [ ] 원그림을 직접 보고 caption과 관련 Methods를 읽는다. 참고한 선택이 실제로 무엇을 표현하는지, 우리 자료의 단위·조건·질문과 무엇이 같고 다른지 기록한다.
- [ ] 패널별로 어떤 축·배치·범례·표기를 채택하거나 조정할지와 그 이유를 근거 figure에 연결한다. 주장하려는 내용의 과학적 근거와 표시 방식의 선례는 각각 구분한다.
- [ ] 필수 표현의 참고 원그림과 설명을 확보하지 못하면 확인할 때까지 제작으로 넘어가지 않는다. IF·피인용 수를 확인하지 못했다면 확인 상태를 기록하고, 확인되지 않은 수치나 높은 순위를 추정하지 않는다.

높은 IF나 피인용 수만으로 표시 방식의 적합성을 판정하지 않는다. 같은 비교를 보여 주는지, 관측 단위와 자료 구조가 맞는지, 원그림과 설명을 직접 확인할 수 있는지 함께 판단한다.
