# 연구 결과의 해석 점검

계산 절차를 설명하는 데 그치지 않고, 계산으로 연구 대상에 관해 무엇을 알게 되었는지 전달한다. 설명의 길이를 늘리는 대신 결과와 해석 사이에 누락된 논리를 보완한다.

## 범위와 근거

- 검토 요청에는 검토 결과를 제시하고, 수정 요청에는 지정한 문서를 수정한다. 설명 점검만으로 새 분석·그림 제작·문서 사본·검사 파일 작성을 시작하지 않는다.
- 최신 문서와 사용자 교정을 확인한다. 연구질문·비교 기준은 프로젝트 지침을 따르고, 필요한 근거는 기존 코드·결과표·원문에서 직접 확인한다.
- 원자료의 관측값, 계산 결과, 해석, 후속 가설을 구분한다. 기존 결과에 새 해석을 추가한 경우 최초 분석의 목적이나 확인된 기전으로 소급하여 기술하지 않는다.
- 근거 위치는 절·표·그림·수식 번호나 파일 위치로 연결한다. 요약과 파일명만으로 근거의 범위를 판단하지 않는다.
- 프로젝트가 지정한 용어집과 표기를 따른다. Cosearch 기본 용어집은 `obsidian/00_Meta/GLOSSARY.md`다. 프로젝트별 금지어·영문 표기·기호 규칙을 공통 규칙으로 확대하지 않는다.

## 분석의 목적과 비교를 확인한다

### 무엇을 알아보기 위한 분석인가?

방법 이름보다 연구에서 구별하려는 실제 관계를 먼저 제시한다. 중간 계산을 최종 연구목적으로 바꾸지 않는다. 모형 추정이 후속 비교를 위한 절차라면 추정 결과를 어디에 사용하는지 연결한다.

보정·변환·자료 제외는 어떤 변동을 포함하거나 제외하며, 비교로 어떤 가능성을 구별하는지 설명한다. 연구 대상인 조건 차이를 자동으로 오류나 제거 대상으로 취급하지 않는다. 새로 제안한 해석에는 현재 자료가 제공하는 근거와 필요한 조건을 함께 제시한다.

### 정확히 무엇과 무엇을 비교했는가?

대상, 측정 반응, 단위와 기준량, 관측 단위, 조건, 비교 기준을 확인한다. ‘기여’, ‘관계’, ‘전체’, ‘안정적’, ‘유지됨’이라는 표현만으로 비교 대상을 대신하지 않는다.

특히 다음 구별이 해석에 영향을 주는지 살핀다.

- 직접 측정한 반응과 모형으로 계산한 반응.
- 개별 대상의 결과와 여러 대상을 합산한 결과.
- 실제 측정한 비교군과 모형 안에서 설정한 계산 기준.
- 여러 집단을 합한 관계와 같은 집단 내부의 관계.
- 단위 변경과 비선형 변환.
- 분석 parameter를 변경한 민감도 분석과 실제 실험 조건의 변화.

비교에서 고정한 대상과 변경한 대상을 명시한다. 계산에서 특정 항을 제외한 결과를 실제 개입이나 독립된 실험의 결과로 설명하지 않는다.

### 기호가 실제 무엇을 가리키는가?

낯선 기호·약어를 다른 미정의 기호·약어로 바꾸는 것은 설명이 아니다. 실제 대상과 측정값부터 정의한다. 시료번호는 어떤 관측 단위의 번호인지, 상대값은 어떤 반응을 무엇과 비교한 값인지 밝힌다. 정의가 인접한 문단에 있으면 연결하고 반복 설명은 줄인다.

수량에는 실제 대상과 세는 단위를 명시한다. 성분의 종류 수, 시료 수, 독립 실험 수, 기술 반복 수를 구분한다. 질량당 측정값과 개체당 측정값 등 기준량도 생략하지 않는다.

## 계산에서 실제 현상의 해석까지 연결한다

**계산에서 확인한 관계 → 실제 측정 대상과의 대응 → 대응이 성립하는 조건 → 연구질문에서 얻은 정보**를 확인한다. 모든 문단에 네 항목을 반복하는 출력 양식이 아니라, 빠진 연결을 찾는 기준이다.

- 계산량이 어떤 측정값에서 산출되었고 실제 대상의 어떤 차이를 나타내려는지 밝힌다. 수학적 항등식, 자료에서 추정한 관계, 실제 작용에 관한 해석을 구분한다.
- ‘부호가 유지되었다’면 무엇의 부호가 어떤 parameter·자료 포함 조건에서 유지되었는지 설명하고, 특정 선택에서만 얻은 결과인지에 관한 판단과 연결한다. 계산 선택에 대한 안정성을 실제 기전의 확인으로 확대하지 않는다.
- 통계량의 차이를 실제 현상으로 해석하는 데 필요한 조건을 구체화한다. ‘적절히 반영한다면’ 대신 어떤 관계가 어떤 범위에서 대응해야 하는지 설명한다.
- 조건부 연관을 인과적 작용으로 바꾸지 않는다. 동시에 인과관계가 확인되지 않았다는 이유만으로 관찰 자료가 구체화한 가능성이나 후속 비교의 의의를 삭제하지 않는다.
- 기대와 다른 결과도 비교 기준에 따라 해석한다. 보조 모형의 성능이 낮다는 이유만으로 별도 연구질문의 모든 탐색 결과를 일괄 폐기하지 않는다.
- 제한은 해당 결론과 연결한다. 미수행 작업 목록이나 ‘추가 연구가 필요하다’만으로 현재 결과의 의의를 대신하지 않는다. 이미 정의한 방법·조건·한계는 반복하지 않는다.

## Figure의 설계와 해석을 연결한다

**연구질문에서 구별할 관계 → 필요한 비교량과 기준 → 시각적 표현 → 독자가 확인할 차이 → 뒷받침되는 해석**이 이어지는지 점검한다.

### 왜 해당 비교량과 표현인가?

- ‘차이를 보기 쉽게 표현했다’ 대신 어떤 시각적 비교가 어떤 과학적 비교에 대응하는지 설명한다. 막대 길이의 차이, 0선에 대한 부호, 기준선과의 거리, 점의 분포 등 판단할 특징을 특정한다.
- 왜 비교량을 알아야 연구질문에 답할 수 있는지 확인한다. 기준값·변환·분해 항의 선택으로 어떤 가능성을 구별할 수 있는지 설명한다. 근거를 확인하되 순환 설명이나 끝없는 배경 설명을 추가하지 않는다.
- 축 범위, 정렬, 단위, 색 구분, 패널 분리가 판단에 영향을 주면 선택 이유를 제시한다. 서로 다른 축 범위나 단위의 크기를 그대로 비교하지 않는다.
- 표현의 실익을 찾지 못하면 설명 부족·중복·설계 변경 필요를 구분한다. 기존 그림에 필연적인 제작 이유를 꾸며 붙이지 않는다.

### 대상과 계산을 먼저 제시하고 색을 연결한다

- ‘회색 막대는 기준이다’보다 어떤 자료·조건으로 계산한 어떤 측정량인지 먼저 설명하고 색·표시를 괄호로 연결한다. 정의 이후에도 판단의 주어는 대상이나 계산량의 이름으로 유지한다.
- 같은 색이 패널마다 다른 대상을 뜻하면 구분한다. 한 패널의 계산을 다른 패널과 독립된 측정 근거로 취급하지 않는다.
- ‘전체적으로’ 대신 무엇을 합산하거나 비교했는지 명시한다. 반복되는 긴 정의는 대상이 분명한 명칭으로 줄이되, 새로운 압축 용어로 대체하지 않는다.

### 그림의 어느 차이가 어떤 판단으로 이어지는가?

- 범례와 결론을 분리해서 나열하지 않고, 실제 비교할 점·막대·선의 관계와 해석을 같은 설명 안에서 연결한다. 그리지 않은 기준선을 표시된 기준선으로 설명하지 않는다.
- 합산 그림은 시작·마지막 막대의 총량과 중간 막대의 가감 항을 구분한다. 정지한 막대가 이동한다고 설명하지 않고 어떤 값에 무엇을 더하거나 차감한 결과인지 기술한다.
- ‘잘 유지된다’, ‘완전하다’는 표현에는 판단 대상을 제시한다. 점 하나의 조건 충족과 관측값 전체의 분포에 관한 판단을 구분한다.
- 필요하면 반대 결과였을 때 그림의 관계가 어떻게 달랐을지 짧게 제시한다. 범례와 수치를 반복하는 대신 현재 비교가 배제하거나 뒷받침하는 가능성을 설명한다.

캡션에는 측정·표현 방식을, 본문에는 그림의 어느 부분에서 연구질문에 대한 근거를 읽는지 제시한다. 수식도 같은 기준으로 각 항을 구분해야 하는 이유와 판단에 주는 정보를 설명한다. 단순한 의의 문장 누락을 새 그림 추가로 대신하지 않는다.

## 검토와 수정

보완할 대목에는 위치, 짧은 원문, 누락된 연결, 근거 범위 내 수정안을 제시한다. 이미 주변에서 충분히 설명한 내용과 재현 부록의 구현 설명에 해석 문장을 억지로 추가하지 않는다.

수정 시 수치·단위·분석 조건·출처·과학적 제한을 유지한다. 핵심 결과는 연구상 얻은 정보부터 제시하고, 상세 방법과 구현 설명은 해당 절에서 설명한다. 수정 후 대상·비교·해석의 연결을 다시 읽는다. 자동 문자열 검사나 형식 점수는 의미의 적절성을 대신하지 않는다.
