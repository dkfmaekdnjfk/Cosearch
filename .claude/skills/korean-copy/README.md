# korean-copy

integration의 한국어 문구 규칙을 기준으로 개발 특화 규칙을 삭제한 스킬이다.
전문 용어는 영문 원문이 있으면 해당 명칭을 우선한다.
구어체·대명사·엠 대시·꺽쇠 금지와 원본 대체 표현표·점검 절차를 유지한다.
수량에는 대상과 세는 단위를 명시하고, 기호·약어에는 실제 대상을 설명한다.

정본: `SKILL.md`. 용어 정의와 운영 절차는 `obsidian/00_Meta/GLOSSARY.md`를 참조한다. 프로젝트 전용 용어와 기록 절차는 `references/project.md`에 둔다.
원본: integration의 `.claude/skills/korean-copy/SKILL.md`.
